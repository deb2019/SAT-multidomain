SAT external feasibility test | UCI Occupancy Detection
Candanedo & Feldheim, UCI dataset 357, https://archive.ics.uci.edu/dataset/357/occupancy-detection
Download https://archive.ics.uci.edu/ml/machine-learning-databases/00357/occupancy_data.zip to this directory and run python experiment.py occupancy.zip. Archive SHA-256: 4ae3f46aa98eedff564a9f6924d1635173e2fd2c816004342a9be93076d3a81a.
Versions: numpy 2.3.5, pandas 2.2.3, scipy 1.17.0, scikit-learn 1.8.0.
Scoring and audit logic follow the previous SAT pilot and https://github.com/deb2019/SAT-multidomain.
Selection and protocol: real time-stamped binary labels from office photographs; dataset, chronological half split and calendar-day batches chosen before looking at outcomes. Five sensor features. Original file boundaries ignored. Source only: seeded stratified 60/20/20 fit/calibrate/reference. Reference chooses the first minimum of the source cost on the fixed 999-point grid. Isotonic ties are retained. Target prevalence for SAT comes from EM on unlabelled daily scores. The last day and other partial days are retained. Cost weights 1 for a false positive, 5 for a false negative. This is a benchmark cost ratio, not an estimate of building-specific financial costs.
The exact one-sided finite-batch test has alpha .05; each budget is a separate fixed design. D = number of disagreements, K = positives in them. Whole-batch random comparator uses the same test conditional on the number of sampled disagreements. Both designs skip labels if D=0. Probability and gain columns are exact expectations under uniform sampling without replacement. No audit outcomes were simulated.
Results: 9 target days, 4 beneficial switches, 1 harmful, 4 no disagreement. Source total 407 units; unconditional SAT 504. Retrospectively selecting the cheaper threshold per day yields 351. A 25-label cap reaches that same total with 67 inspected labels; uniform sampling saves 0.0000278 units relative to source. The pooled targeted saving is 56/407 = 13.76%, before annotation cost, over these same nine batches.
Interpretation: concentrated disagreements make targeting efficient. At the 25-label cap, three beneficial days exhaust all disagreements. On the fourth beneficial day 25 of 39 are inspected; 14 positive-cost units saved on the remaining unaudited decisions. At that budget all 56 beneficial differences are avoided false positives. Calendar days are not independent replications. No claim about the next batch, monetary net benefit, or a new general algorithm.
